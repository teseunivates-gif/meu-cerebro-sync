Meu Cérebro - Sincronização

Aplicativo de uso pessoal para sincronização de arquivos acadêmicos selecionados entre um computador local e o Google Drive.

Funcionamento

O aplicativo utiliza a API do Google Drive para criar e atualizar arquivos previamente autorizados pelo usuário.

O acesso é restrito à conta Google autorizada. O aplicativo não disponibiliza publicamente os documentos sincronizados.
